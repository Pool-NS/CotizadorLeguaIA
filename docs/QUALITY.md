# Calidad del producto y proceso

`qa/iso25010/` describe evaluación basada en ISO/IEC 25010:2023, no aprobación. `qa/square/` usa SQuaRE como vocabulario/marco, no certificación. `qa/iso9001/` documenta prácticas de gestión de calidad; no afirma certificación. `qa/clean_code/` registra revisión de código. SonarQube está preparado como configuración, pero debe ejecutarse contra una instancia disponible.
